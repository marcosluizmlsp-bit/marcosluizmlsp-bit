📌 Projetos em destaque
MaterialFlow — Sistema de gerenciamento de estoque
Projeto de estudo para desenvolver uma aplicação web voltada ao cadastro de produtos e ao controle de estoque, relacionando desenvolvimento de software com conceitos de planejamento e gestão de materiais.
Tecnologias planejadas: HTML, CSS, JavaScript, Node.js, Express e PostgreSQL.
Objetivos de aprendizagem:
- Criar uma interface para cadastro e consulta de produtos.
- Desenvolver uma API REST para comunicação entre frontend e backend.
- Organizar o backend em rotas, controllers, services e repositories.
- Persistir e consultar dados em um banco de dados relacional.
- Aplicar conceitos de estoque mínimo e acompanhamento de quantidades.
O projeto está em desenvolvimento e será atualizado conforme novas funcionalidades forem implementadas.
